Servidores de Internet

01 · CONCEPTO

¿Qué es un servidor?

Un servidor es un sistema compuesto por hardware y software que almacena y distribuye contenido o servicios a otros equipos.

⌘

Atiende solicitudes de los clientes

Cuando una persona abre una página web o utiliza una aplicación, su navegador o aplicación solicita información. El servidor procesa la petición y devuelve el contenido solicitado mediante protocolos como HTTP.

▣

Hardware

Es la parte física que aloja los servicios, por ejemplo, el procesador, la memoria RAM y el almacenamiento.

⌘

Software

Son los programas que gestionan las solicitudes y entregan el contenido, como Apache, Nginx o Microsoft IIS.

02 · PROCESO

¿Cómo funciona?

La comunicación básica entre un cliente y un servidor se puede resumir en tres pasos.

01
⌕

Solicitud del cliente

El usuario escribe una dirección o selecciona un enlace desde su navegador.

→
02
⚙

Procesamiento

El servidor recibe la petición y determina qué recurso o información debe entregar.

→
03
▤

Entrega del contenido

El servidor envía los archivos o datos y el navegador los muestra al usuario.

Ejemplo cotidiano: al entrar a una página web, el navegador actúa como cliente, solicita la información y el servidor se la entrega.

03 · CLASIFICACIÓN

Tipos de servidores

Cada tipo de servidor cumple una función específica dentro de una red.

⌘

Servidor web

Almacena y entrega páginas web, atendiendo solicitudes HTTP de los navegadores.

Páginas y sitios web
✉

Servidor de correo

Gestiona el envío y la recepción de mensajes de correo electrónico mediante protocolos como SMTP.

Correo electrónico
⇄

Servidor de archivos (FTP)

Permite transferir archivos entre equipos y usuarios conectados a la red.

Transferencia de archivos
◎

Servidor DNS

Traduce nombres de dominio, como www.google.com, a direcciones IP que los equipos pueden utilizar.

Nombres de dominio

04 · RENDIMIENTO

Características principales

La capacidad de respuesta de un servidor depende de varios recursos y medidas de protección.

01

Procesador (CPU)

Permite ejecutar tareas y atender solicitudes de forma simultánea.

02

Memoria RAM

Ayuda a ejecutar procesos y manejar datos temporalmente con rapidez.

03

Almacenamiento

Los discos HDD y SSD guardan archivos, aplicaciones y datos; los SSD suelen ser más rápidos.

04

Conexión de red

La velocidad de conexión influye en la rapidez con que se intercambia la información.

05

Seguridad

Los firewalls, el cifrado y otros controles ayudan a prevenir accesos no autorizados.

IDEA CLAVE

Los servidores hacen posible muchos servicios de Internet.

Reciben solicitudes, procesan información y responden a los clientes. Su hardware, software, conectividad y seguridad contribuyen a que los servicios funcionen de manera eficiente.
